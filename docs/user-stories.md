# User Stories

Format: As a [type of user], I want [goal], so that [reason or benefit].

1. As a community responder, I want to describe injury symptoms using text or voice, so that the system can evaluate hidden fractures or dislocations that a camera cannot see.(FR1)
2. As an untrained bystander, I want the system to suggest suitable household items to use as substitutes, so that I can quickly improvise a sling, splint, or bandage when standard medical kits are unavailable. (FR2)
