# EMERGENCY INJURY ASSESSMENT WITH FIRST AID RECOMMENDER SUPPORT SYSTEM

This project provides real-time injury assessment and first aid guidance using computer vision and fuzzy logic to help untrained community members and first responders manage sudden emergency injuries safely when standard first aid equipment is unavailable.

## Problem statement
Untrained community members and non-expert first responders may struggle to assess limb injuries and choose suitable first-aid steps during emergencies (Abraham et al., 2023). This problem becomes more difficult when standard first-aid supplies are unavailable and users do not know whether alternative materials are safe to use 
(Hewett Brumberg et al., 2024). Although computer vision can support injury assessment through image analysis, it may not provide enough information to guide users through the correct first-aid procedures (Clinical Validation of Computer Vision, 2023). Therefore, this project proposes an Emergency Injury Assessment with First Aid Recommender Support System that uses computer vision to support limb injury assessment and provide clear, safety-focused first-aid guidance.
